WorkflowOS is a South African small-business management prototype with a database-backed dashboard, product catalogue, inventory tracking, sales records, and barcode-ready workflows.

Static GitHub Pages preview. Pages cannot run the WorkflowOS Express API or SQLite database. Sign-in, business data, sales, barcode lookup, and dashboard operations are not available on this static page. The full prototype currently runs locally; a separate API/database host must be configured before this site can serve as the live application.
