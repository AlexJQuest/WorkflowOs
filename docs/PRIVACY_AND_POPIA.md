# Privacy and POPIA

## Current position

This is a prototype and not a legal compliance claim. It is designed with privacy-first principles, but no formal legal review has been completed.

## Current controls

- Personal data is stored in a local SQLite database rather than in browser memory alone.
- Session data is treated as sensitive and is not exposed in the frontend.
- The business membership model is designed to keep tenant data separated.

## Unresolved legal work

- Privacy notice requirements
- Lawful basis for processing
- Data subject access and deletion procedures
- Consent and communication preferences
- Processor and operator documentation

## Recommendation

Use this project as a technical foundation and engage qualified South African legal review before client launch or live data handling.
